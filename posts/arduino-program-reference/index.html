Arduino编程语句参考

Arduino程序可以分为三个主要部分：结构，数值（变量与常量）和函数。

提示：本文同时兼容 AVR‑Arduino 和 ESP32‑S3，部分函数行为会因硬件平台略有差异。

结构

基础程序结构

语法 说明
setup() 上电/复位后仅运行一次，用于初始化引脚、串口、外设。无返回值。
loop() setup执行完毕后无限循环执行，项目主业务逻辑写在此函数内。无返回值。

控制结构

  • if：条件判断，如果括号内表达式结果为真，则执行内部代码块
  • if...else：二分支条件判断；条件成立执行if分支，不成立执行else分支
  • for：循环，多用于已知循环次数的场景
  • switch case：多分支条件判断，用于匹配变量多种离散取值；不要忘记break，否则会穿透执行后续case
  • while：当条件表达式为真时，反复执行循环体；条件不成立直接跳出
  • do... while：先执行1次循环体，之后再判断条件，条件为真继续循环；至少运行一次
  • break：跳出for/while循环，或者跳出switch‑case语句
  • continue：跳过本次循环剩下代码，直接进入下一轮循环判断
  • return：函数返回，提前结束当前函数；有返回值函数需要携带返回数据
  • goto：跳转到代码标记位置，Arduino语法支持，但不推荐普通项目使用，容易破坏代码逻辑

进阶语法

语法 说明
; 语句结束分号，绝大多数代码行末尾必须带分号；for()、if()、函数定义后不要在括号后加分号
{ } 大括号，包裹代码块（函数、if、循环内部）；建议成对书写
// 单行注释，//之后本行全部内容不会编译执行
/* */ 多行注释，/*与*/之间全部内容作为注释，可跨越多行
#define 宏定义，预处理阶段文本替换；不是真正变量，没有类型，注意避免括号陷阱
#include 引入外部库或者头文件，<>用于系统库，""用于本地自定义头文件

数值

常量

  • IO电平常量：HIGH / LOW
  • 引脚模式常量：INPUT / OUTPUT / INPUT_PULLUP
  • 布尔常量：true / false
  • 整数常量：支持十进制、十六进制0x、八进制0开头
  • 浮点数常量：带小数点数字，例如3.14

注意：ESP32没有 INPUT_PULLDOWN，该常量仅部分AVR板子支持。

数据类型

类型 中文名称 说明
void 无返回值 仅用于函数声明，代表函数不返回任何数据，不能用来定义变量
boolean 布尔型 取值 true / false；底层存储为1字节
char 字符型 单个字符，1字节；AVR是有符号(-128~127)，ESP32 char默认为无符号
unsigned char 无符号字符型 1字节，数值范围 0‑255
byte 字节型 等价 unsigned char，范围0‑255，硬件位操作常用
int 整型 AVR：16位 -32768 ~ 32767；ESP32是32位int，范围大幅扩大
word 字型 无符号16位，取值 0‑65535
long 长整型 32位带符号整数
float 单精度浮点型 4字节，保存小数
double 双精度浮点 AVR为8字节；ESP32下 double 和 float 完全等价，没有更高精度
String 字符串对象 Arduino封装类，方便文本操作；内存碎片风险，嵌入式谨慎高频使用
array 数组 相同类型数据集合；int arr[10]; 定义数组

类型转换函数

强制把数据转为对应类型

  • char() 转为 char
  • byte() 转为 byte
  • int() 转为 int
  • word() 转为 word
  • long() 转为 long
  • float() 转为 float

变量范围与限定符

  • 变量作用域
    • 全局变量：写在所有函数外面，整个程序全部函数都可以访问；上电初始化一次
    • 局部变量：写在函数/大括号{}内部，仅该代码块内有效；每次进入代码块重新创建
  • static：静态局部变量；函数退出后，变量数值保留，不会销毁
  • volatile：易变限定符；阻止编译器优化读取，中断服务函数访问共享变量必须加volatile
  • const：常量，赋值后数值不可修改

运算符

算术运算符

  • = 赋值运算符，把右侧值存入左侧变量，不等于数学等于
  • + 加法
  • - 减法
  • * 乘法
  • / 除法；整数相除结果为整数，舍弃小数
  • % 取模（求余数）；仅支持整数，不能用于浮点数

关系运算符（比较运算，返回true/false）

  • == 判断是否相等，不要和赋值=混淆
  • != 判断不等于
  • < 小于
  • > 大于
  • <= 小于等于
  • >= 大于等于

布尔逻辑运算符（逻辑与/或/非）

  • && 逻辑与，两边条件全部为真结果才为真
  • || 逻辑或，任意一边条件为真结果即为真
  • ! 逻辑非，取反，真变假，假变真

位运算符

  • & 按位与
  • | 按位或
  • ^ 按位异或
  • ~ 按位取反
  • << 位左移
  • >> 位右移

指针运算

  • 指针的概念
  • 指针变量

提示：普通Arduino项目很少用到指针，高级C语言特性。

工具

  • sizeof() 获取变量/数据类型占用内存字节大小

函数

Serial.begin(波特率);

数字 I/O

  • pinMode(pin, mode) 设置引脚模式：INPUT / OUTPUT / INPUT_PULLUP
  • digitalWrite(pin, val) 输出引脚电平：HIGH / LOW
  • digitalRead(pin) 读取数字引脚电平，返回HIGH或LOW

模拟 I/O

  • analogRead(pin) 读取 ADC 模拟输入；返回采样数值；ESP32 ADC 存在噪声
  • analogWrite(pin, duty) PWM 脉冲宽度调制输出；不是 DAC 模拟电压输出

高级 I/O

  • tone(pin, freq) 在指定引脚输出方波，常用于驱动蜂鸣器
  • noTone(pin) 停止 tone 方波输出
  • shiftOut(dataPin, clockPin, bitOrder, value) 串行移位输出
  • shiftIn(dataPin, clockPin, bitOrder) 串行移位输入
  • pulseIn(pin, value) 读取引脚上指定电平脉冲持续时间（微秒）

时间函数

millis/micros 为非阻塞，推荐优先使用；delay 是阻塞延时，程序卡在该处不能做别的任务

  • millis() 返回系统上电运行总毫秒数，返回 unsigned long
  • micros() 返回系统上电运行总微秒数，返回 unsigned long
  • delay(ms) 毫秒级阻塞延时
  • delayMicroseconds(us) 微秒级阻塞延时

数学函数

  • min(a,b) 返回两个数最小值
  • max(a,b) 返回两个数最大值
  • abs(x) 返回绝对值
  • constrain(x,min,max) 将数值限制在 min‑max 区间，超出直接截断到边界
  • map(val,in_min,in_max,out_min,out_max) 将输入区间线性映射到输出区间
  • pow(base,exp) 幂运算，求 base 的 exp 次方，返回 float
  • sqrt(x) 平方根运算

三角函数

⚠️ 参数单位是弧度，不是角度，角度需要先转换 角度 * PI / 180

  • sin(rad) 正弦
  • cos(rad) 余弦
  • tan(rad) 正切

随机数

  • random(max) / random(min,max) 获取随机整数；范围 [min, max‑1]，上限不包含
  • randomSeed(seed) 设置随机数种子；通常用analogRead(悬空引脚)获取噪声做种子

位与字节操作

  • lowByte() 获取 16 位数值低字节
  • highByte() 获取 16 位数值高字节
  • bitRead() 读取指定 bit 位
  • bitWrite() 修改指定 bit 位
  • bitSet() 将指定 bit 置 1
  • bitClear() 将指定 bit 置 0
  • bit() 返回第 n 位掩码数值
